GitHub repositories and users autocomplete component

Your task is to create a reusable native autocomplete component/screen which fetches matching GitHub users and repositories for a given string of characters.

Requirements:

- Do not use an existing autocomplete library.
- Minimum 3 characters to start search.
- Fetch both users and repositories.
- Combine results into one list and sort alphabetically using repository name and profile/login name.
- Limit results to 50 items per request.
- Show visual feedback for loading, empty results, and error state.
- Handle rapid input changes sensibly.
- The component should be reusable, not hardcoded to a single screen.
- The solution should include a meaningful snippet showing how you test the code.

Tech stack: Android+Kotlin

Code challenge artifact: URL to a publicly accessible Git repository
